# Source Code

All GridPulse source code lives in this directory.

## Structure

```
src/
├── requirements.txt          ← Python dependencies (backend + tests)
├── .env.example              ← Environment variable template (copy to .env)
│
├── data/
│   ├── generate_dataset.py   ← Generates grid_data.csv (run this first)
│   └── grid_data.csv         ← Synthetic grid dataset (generated, not hand-crafted)
│
├── backend/
│   ├── main.py               ← FastAPI application entry point
│   ├── config.py             ← Settings loaded from .env
│   ├── routers/              ← One file per API endpoint group
│   │   ├── status.py         ← GET /api/status
│   │   ├── forecast.py       ← GET /api/forecast
│   │   ├── renewable.py      ← GET /api/renewable
│   │   ├── alerts.py         ← GET /api/alerts
│   │   ├── simulate.py       ← GET/POST /api/simulate
│   │   └── brief.py          ← GET /api/brief, POST /api/brief/refresh
│   ├── services/             ← Business logic
│   │   ├── data_loader.py    ← CSV loader and rolling window provider
│   │   ├── forecaster.py     ← Granite TTM + STL fallback
│   │   ├── renewable_monitor.py ← Physics-based expected generation + metrics
│   │   ├── anomaly_engine.py ← 12 threshold rules + alert structs
│   │   ├── simulator.py      ← 4-action deterministic scorer
│   │   └── brief_generator.py ← Granite Instruct + Jinja2 template
│   └── models/
│       └── schemas.py        ← Pydantic v2 response models
│
├── mcp-server/               ← IBM Bob MCP integration
│   ├── index.ts              ← 3 tools: get_grid_status, get_active_alerts, get_operator_brief
│   ├── package.json
│   └── tsconfig.json
│
├── frontend/                 ← React 18 dashboard
│   ├── index.html
│   ├── vite.config.js
│   ├── package.json
│   └── src/
│       ├── main.jsx
│       ├── App.jsx
│       ├── components/
│       │   ├── KPICard.jsx
│       │   ├── ForecastChart.jsx
│       │   ├── RenewableChart.jsx
│       │   ├── AlertPanel.jsx
│       │   ├── SimulationPanel.jsx
│       │   └── OperatorBrief.jsx
│       └── styles/
│           └── main.css
│
└── tests/
    ├── test_data_loader.py
    ├── test_forecaster.py
    ├── test_renewable_monitor.py
    ├── test_anomaly_engine.py
    ├── test_simulator.py
    ├── test_brief_generator.py
    └── test_api.py
```

## Quick Start

```bash
# From this directory (src/)
pip install -r requirements.txt
python data/generate_dataset.py
uvicorn backend.main:app --reload --port 8000
```

See [`../docs/setup-guide.md`](../docs/setup-guide.md) for the full setup instructions.

## Important Notes

- Never commit `.env` — it is in `.gitignore`. Use `.env.example` as your template.
- `grid_data.csv` is generated by `generate_dataset.py` and committed to the repo for convenience.
- All five features work without IBM Cloud credentials (fallback mode is always active).
- Tests do not require IBM Cloud credentials — watsonx.ai is mocked.
