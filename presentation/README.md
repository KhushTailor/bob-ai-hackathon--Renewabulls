# Presentation

Add the GridPulse slide deck here before submission.

## Required File

  slides.pdf    (preferred)
  slides.pptx   (acceptable alternative)

## Recommended Slide Structure

1. Problem — who, what, why it hurts (renewable curtailment, operator cognitive load)
2. Solution — what GridPulse does and how it works (one-sentence per feature)
3. Architecture — system diagram showing the five features and IBM technology connections
4. IBM Technology Integration — where and how IBM Bob, Granite TTM, and Granite Instruct
   are used (be specific; refer to docs/ibm-bob-integration.md)
5. Demo highlights — 2–3 screenshots from the running application
6. Impact — what GridPulse could become beyond the hackathon prototype
